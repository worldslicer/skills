# Skills

Agent Skills for [OASys](https://github.com/OverHCV/OASys) — the agentic programming engine.

| Skill | What it teaches an agent |
|---|---|
| [`oasys`](oasys/SKILL.md) | The `.os` language, devices (books, pages, lines, cells), agents and kits, running and benchmarking devices with the `oasys` CLI |

## Install

```sh
pnpx skills add woldslice/skills -s oasys
```

The source of truth lives in the OASys repo (`skills/oasys/`); every `.os` example in it is compiled by a test there.
